# 📊 SK 股市每日复盘

基于 **DeepSeek Harness (DSH)** 的动态 Cordis 插件:每天 7:00(北京时间)自动拉取 A 股最新交易日数据,按个人复盘风格生成**复盘报告(Markdown)**与**可视化看板**。

## ✨ 功能

| 模块 | 说明 |
| --- | --- |
| **一字板全景** | 同花顺板型精确识别一字板/T字板/换手板;与前一交易日对比自动分类为 **连板加单一字 / 新增一字 / 首板一字 / T字(竞价封单强) / 一字封单减弱 / 持平**,标注「N进N+1」几板、封单金额与封单排名(第一/二/三) |
| **竞价封单** | 每个交易日 **9:30 自动采集**早盘竞价结束后的一字板封单(区别于收盘封单);未采集到当日数据时回退显示收盘封单并标注 |
| **连板天梯** | 只展示**连续涨停**(逐股日 K 回推连续板数,非「几天几板」统计),最高板=最高连续板数;带 **放量晋级/缩量晋级/平量晋级**(量比)、一字/T字/换手板型、涨停原因(同花顺口径)、首封时间、炸板次数 |
| **断板反包** | 独立选项卡:中间有断板、再反包涨停的「几天几板」个股 |
| **概念 TOP3** | 当日涨幅前 3 概念板块;每个概念展示**人气 TOP5 个股**(按成交额排名);连板天梯中 📌 标注成分股 |
| **个股分时图** | 看板中任意**股票名可点击**,弹出当日**分时图**(东方财富分时 + 腾讯降级):分时线/均价线/昨收基准/成交量柱,红涨绿跌,支持明暗主题 |
| **近7日概览** | 图表化:上证收盘折线、涨跌幅红绿柱、**大盘成交额(沪深两市合计)柱状图**、涨停/跌停双折线 + 精确数值表 |
| **复盘文档** | 自动生成仿个人风格的 Markdown(`.stock-review/reviews/MM.DD.md`):一字板对比表 + 连板天梯表 + 断板反包 + 断板提示 + 近7日概览 |
| **定时任务** | 每日 07:00 自动生成复盘;每日 09:30 采集竞价封单;重启后自动重排 |

## 🖥 界面

- **入口**:对话流 Run 卡片「打开看板」;设置 → 插件 → **SK** 页签
- 面板**居中**显示,支持 **⛶ 全屏**;明/暗双主题自动跟随(深蓝紫金融配色)
- 5 个选项卡:一字板 / 连板天梯 / 断板反包 / 概念TOP3 / 近7日
- **点击任意股票名 → 弹出当日分时图**

## 🔌 部署到 DSH

本插件为 DSH 动态 Cordis 插件(Host + Client 双端),源码见 [`src/host.js`](src/host.js) 与 [`src/client.js`](src/client.js)。

**方式一:动态插件(推荐)**

在 DSH 会话中通过动态插件能力(`cordis_define`)粘贴 `src/host.js` 与 `src/client.js` 中的代码即可创建;首次运行浏览器端 UI 需在界面批准。

**方式二:静态插件(进阶)**

将 `src/host.js` / `src/client.js` 改造为 DSH 静态插件并在宿主 `cordis.yml` 挂载(需按 DSH 静态插件规范补充 `dsh.client` 入口与包结构)。

## 📦 数据与存储

- **数据源(公开接口)**:同花顺(涨停池/涨停原因/封单/板型)· 东方财富(概念板块/跌停/成分股)· 新浪/腾讯(指数与个股日 K 备用源)
- **容错**:EM K 线接口不可用时自动降级 腾讯→新浪;大盘成交额缺失时按实时成交额标定估算(标注「估算」,EM 恢复后自动切回精确值)
- **本地产物**:`<workspace>/.stock-review/` 下保存 `snapshot.json`(近7日涨跌停统计 + 竞价封单)与 `reviews/MM.DD.md`(每日复盘文档)
- **依赖**:插件在 Host 侧通过 `subprocess` 调用 `curl.exe` 抓取数据(HTTP/HTTPS),通过 `fs` 服务(显式沙箱策略)写盘

## ⚠️ 说明

- 封单为**收盘封单口径**的时期已在界面/文档标注;自部署起每个交易日 9:30 起自动采集**竞价封单**
- 大盘成交额 = 沪深两市合计(上证指数 + 深证综指)
- 涨停数按日取自同花顺;跌停数当日取自东财、历史值随每日运行自动累积
- 数据仅供个人复盘参考,不构成投资建议
